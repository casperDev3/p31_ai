# План: примітивний перцептрон з візуалізацією в HTML

## Мета

Один самодостатній файл `exp/perceptron_claude-fable-5.html` (без бібліотек, без бандлера — як решта семплів у репо): класичний перцептрон Розенблата, що вчиться розділяти 2D-точки двох класів, з живою візуалізацією процесу навчання на `<canvas>`.

## Що саме реалізуємо

### 1. Модель (чистий JS, ~40 рядків)

- Перцептрон з двома входами (x, y), вагами `w1, w2` і зсувом `b`.
- Активація — сходинка: `output = (w1*x + w2*y + b) >= 0 ? 1 : 0`.
- Правило навчання Розенблата:
  `w += lr * (target - output) * input`, `b += lr * (target - output)`.
- Навчання по одній точці за крок (онлайн), щоб рух лінії було видно.

### 2. Дані

- Генератор лінійно роздільних точок: випадкова «справжня» лінія, ~60–100 точок, клас за стороною лінії. Невеликий зазор біля лінії, щоб збіжність була гарантована.
- Опційно: клік по канвасу додає точку (ЛКМ — клас 0, з затиснутим Shift — клас 1).

### 3. Візуалізація на canvas

- Точки двох класів — два кольори; неправильно класифіковані зараз — з обводкою.
- Поточна розділова лінія `w1*x + w2*y + b = 0` — жирна; «справжня» лінія генератора — пунктиром.
- Заливка півплощин напівпрозорими кольорами рішення.
- Підсвітка точки, на якій щойно зроблено крок навчання.

### 4. Панель керування і стан

- Кнопки: **Step** (один крок), **Train** (анімація через `requestAnimationFrame`, ~N кроків/кадр), **Pause**, **Reset** (нові ваги), **New data**.
- Слайдер learning rate (0.001–1, лог-шкала).
- Індикатори: епоха, кількість помилок за останній прохід, поточні `w1, w2, b`.
- Авто-стоп, коли помилок за повну епоху нуль («Збіглося за N епох»).

### 5. Бонус (якщо лишиться запал)

- Графік кількості помилок по епохах (маленький другий canvas).
- Перемикач на нероздільні дані (XOR-подібні), щоб показати, чому перцептрон там не збігається — гарний навчальний момент.

## Структура файлу

Один HTML: `<style>` інлайн (як у всіх семплах), розмітка (canvas + панель), `<script>` з трьома блоками — `Perceptron`-клас, генератор даних, рендер/цикл UI. Без модулів, без залежностей.

## Кроки виконання

1. Скелет HTML + canvas + панель керування (статичний).
2. Генератор даних + рендер точок.
3. Клас перцептрона + кнопка Step, рендер лінії.
4. Анімований Train/Pause/Reset, авто-стоп, лічильники.
5. Поліровка: підсвітки, заливка півплощин, слайдер lr.
6. Створити нотатку `memories/perceptron_claude-fable-5.md` (за конвенцією репо).

## Критерії готовності

- Відкривається подвійним кліком, працює без мережі.
- На роздільних даних збігається за видиму кількість кроків, лінія анімовано «доїжджає» до правильної.
- Reset/New data не ламають стан; Train можна перервати в будь-який момент.
