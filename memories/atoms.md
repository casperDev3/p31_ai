# atoms (exp/)

**Path:** `exp/atoms.html`
**Size:** ~810 lines (single file)
**Language:** Ukrainian (`lang="uk"`)

## What it is

A standalone canvas experiment — "Атоми — Electron Attraction." Particle/electron attraction visualization with a custom cursor. Lives in `exp/` (loose experiments, not games or landings).

## Style / approach

- Near-black background (`#03030a`), full-viewport canvas, `cursor: none` (custom cursor drawn on canvas).
- Indigo accent (`rgba(129, 140, 248, ...)`) — same family as [[antigravity-landing]].
- `JetBrains Mono` / `Fira Code` for the tiny info HUD at the bottom (`#info`).
- Reset button (`#reset-btn`) centered with translucent background and indigo border.

## How to run

```bash
open exp/atoms.html
```

## When to use as reference

It's a creative-coding sketch — useful as a baseline for canvas/particle work, but not part of the games or landings collections. If you add more experiments, put them under `exp/`.
