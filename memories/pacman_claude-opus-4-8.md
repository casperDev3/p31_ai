# pacman_claude-opus-4-8

Pac-Man, варіант Claude Opus 4.8. Один самодостатній файл — `games/pacman_claude-opus-4-8.html` (HTML + CSS + JS inline, без залежностей). Відкривати у браузері: `open games/pacman_claude-opus-4-8.html`.

## Що всередині

- **Рендер**: один `<canvas>` 28×30 клітинок по 20px (560×600). Лабіринт заданий масивом рядків `LEGEND` (легенда: `0` порожньо, `1` стіна, `2` крапка, `3` енерджайзер, `4` ворота дому привидів, `5` тунель). Стіни малюються як скруглені прямокутники.
- **Рух по сітці**: сутності рухаються вільно в пікселях, повертають лише у центрі клітинки (`moveEntity`); є горизонтальний тунель (вихід за край → поява з іншого боку).
- **Привиди**: 4 шт. з класичною ЇхньоюAI поведінкою цілей — blinky (прямо на пакмена), pinky (на 4 клітинки попереду), inky (відзеркалення відносно blinky), clyde (наближається/тікає за порогом відстані 8). Поетапний випуск з дому через `releaseDelay`. Енерджайзер → `frightened` (тікають, синіють, блимають перед кінцем), з'їдені → очі повертаються в дім зі швидкістю 3.4.
- **Стан-машина**: `state` ∈ `menu | ready | playing | paused | dead | won | over`. Початковий стан — `menu` (важливо: до фікса був `ready` з нульовим таймером, через що гра автостартувала під оверлеєм).
- **Керування**: стрілки / WASD, `P` — пауза, свайпи на тач-екранах.
- **Прогрес**: рахунок (крапка 10, енерджайзер 50, привид 200, рівень +500), 3 життя, рівні з наростанням швидкості привидів. Зібрав усі крапки → наступний рівень.

## Нотатки з верифікації

- Рендер, відсутність console-помилок і фікс автостарту перевірені через Claude Preview (статичний сервер).
- У headless-прев'ю в фоні `requestAnimationFrame`/таймери жорстко тротляться (~2 кадри/с), тож рахунок «стоїть» — це артефакт середовища, не баг. У реальному фокусованому браузері гра йде на 60fps.

Дотримано конвенції репозиторію: семпл лежить у `games/` з назвою `<topic>_<tool>.html`; не змішувати з іншими варіантами.
