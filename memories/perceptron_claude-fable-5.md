# perceptron_claude-fable-5.html

Інтерактивний перцептрон Розенблата з візуалізацією навчання. Згенеровано Claude Fable 5. План: `.docs/plans/perceptron_claude-fable-5.md`.

## Що це

Один самодостідний HTML у `exp/` — без бібліотек і збірки, відкривається подвійним кліком. Естетика: «лабораторний осцилограф 1958 року» (рік перцептрона) — темна фосфорна панель, IBM Plex Mono + Fraunces (Google Fonts з graceful fallback на monospace офлайн), плівкове зерно через інлайновий SVG-шум.

## Механіка

- `Perceptron` — 2 входи, ваги `w1, w2`, зсув `b`, сходинкова активація; правило навчання Розенблата (`w += lr * (target - out) * input`).
- Координати нормалізовані до `[-1, 1]²`; онлайн-навчання — один апдейт ваг за кадр (`requestAnimationFrame`), щоб рух розділової лінії було видно.
- `makeSeparableData()` — випадкова «справжня» лінія + зазор `MARGIN = 0.09` біля неї → гарантована збіжність. «Справжня» межа малюється пунктиром.
- `makeXorData()` — 4 гаусові кластери по кутах, XOR-розмітка; авто-стоп через `MAX_EPOCHS = 400` зі статусом «no convergence» (навчальний момент: межі одношарового перцептрона).
- Заливка півплощин — кліпінг квадрата до півплощини (Sutherland–Hodgman у `halfPlanePolygon`).
- `step()` прокручує вибірку вперед до першого реального апдейту ваг (коректні точки проскакують), рахує помилки за повний прохід; нуль помилок за епоху → статус «converged».

## UI

- Кнопки Train/Pause (одна кнопка-тогл), Step, Reset W, New data.
- Слайдер learning rate — лог-шкала 10⁻³…10⁰.
- Readout: епоха, помилки за останній прохід, поточні ваги; лампа статусу (idle / training / converged / no convergence).
- Маленький canvas-графік помилок по епохах.
- Клік по полю додає точку класу A, Shift+клік — класу B (скидає прапорець збіжності).
- Неправильно класифіковані точки обведені червоним; точка останнього апдейту — пунктирне кільце.

## Якщо правити

Не підтягувати патерни з інших семплів (правило репо «не схрещувати варіанти»). Вся логіка в одному `<script>`: блок model → data → canvas → UI.
